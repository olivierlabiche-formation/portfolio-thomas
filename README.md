# Portfolio de Thomas

Site vitrine responsive d'un graphiste freelance, réalisé dans le cadre de la formation « Comprendre les bases du web et du code pour appréhender le no code ».

## Structure

- `index.html` : la page du site
- `styles/style.css` : la feuille de style
- `assets/` : les images et le favicon

## Lancer le site

Ouvrir le dossier dans VS Code, puis cliquer sur « Go Live » (extension Live Server).
